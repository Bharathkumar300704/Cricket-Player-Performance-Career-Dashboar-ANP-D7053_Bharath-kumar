# 🏏 Cricket Player Performance & Career Intelligence Dashboard

The **Cricket Player Performance & Career Intelligence Dashboard** is a Power BI-based Business Intelligence project designed to analyze cricket players' career performance, consistency, progression, and overall match impact. The dashboard transforms historical cricket data into meaningful visual insights that help users understand player performance across seasons, opponents, venues, and match situations.

The project focuses on building an interactive and professional analytics solution using **Power BI, Power Query, DAX, and Excel/CSV data**. It will include player career analysis, batting and bowling intelligence, player comparison, performance trends, and a customized Player Intelligence Score.
